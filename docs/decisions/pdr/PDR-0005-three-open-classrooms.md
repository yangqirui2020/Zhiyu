# 三教室体验与真实/合成明确分离

依据用户当前明确指令与 PROP-0007，开放 101 真实摘要教室、102 基础与项目合成教室、103 AI 与自主编程合成教室。目录是路由/门牌/后续教室的共同真相源；每间题目、叙事、来源、示例、revision、证据均独立。旧真实资产不可变，目录展示覆盖旧预览文案但不改分析资产。

合成教室沿用 provenance.mode=mock，新增 source.provider=synthetic、textKind=synthetic_excerpt，rc.2 兼容扩展。所有学生详情、引文与结果注明合成；不展示虚假知乎原文链接。真实 Snapshot 校验必须拒绝 synthetic。不存在真实问题链接的教室出口标「去知乎搜索这个问题」。

合成教室也复用 Candidate/learning 服务：精确示例返回 mock，其他输入实时处理并标 Live，比较范围始终是本班合成材料；无法分析时保留输入、Retry/Use Sample，不套结果。课堂人数不能代表支持率或社会共识。既有开发 fixture 仍只限显式开发模式。

空间按真实人数适配，小班使用紧凑研讨桌、大班使用多桌组；同一来源仍只显示一个学生。主路径增加贯穿的阶段提示与主动下载课堂笔记，下载不等于知乎发布，不做自动持久化或自动发布。跨教室卸载取消请求并清空个人状态。

展示坐标按屏幕重新排布，保留领域分组；因此不把像素距离称为定量相似度，固定披露「按论证路径分组；组内座次与颜色不表示排名」。手机采用教室与操作区上下排列，避免固定面板遮挡半间教室。旧重复进度浮层移除，由顶部统一进度承载。
