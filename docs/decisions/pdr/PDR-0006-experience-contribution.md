# 用户经验贡献与主动邀请

用户明确选择 PROP-0008 的“经验入席 + 黑板更新 + 分享邀请”。新增用户自述路径和参与者角色：亲历、条件、疑问或反例都能进入整理过程，不要求观点新颖。原 Candidate 仍只表示当前样本覆盖较少，未满足判断时不伪造候选结论。

贡献的事件、做法、结果必须保持用户原输入；一句整理和适用边界可由现有学习结果提供草稿，最终由用户修改、确认。未经确认不新增黑板材料。自述始终标“用户自述 · 未独立核验”，虚构例子保持示例身份；用户修改示例不自动把它变成真实经历，须显式切换到自己的经历并重新填写。

黑板的新增条目仅属于本次浏览器课堂，不写入真实 Snapshot、不重算原分组、不伪称其他用户可见或原作者同意。撤回、Reset 和切题删除本次条目；下载由用户主动执行。画布最多显示本次参与者一个座位，人数不代表新增知乎来源。

复用既有 learning-turn API 与 HMAC；无模型时允许明确“自己整理”路径，不能把它显示成 AI 成功。分享邀请含问题、固定邀请问句和教室链接，不把经历、回答或 token 放进 URL，不自动发送。无作品专属链接时仅开放标明“活动广场”的官方入口。

本轮不做条件重排、公共贡献存储、OAuth 登录、访问量或人气造数。人气奖效果未验证；提交与真实用户试用由参赛者完成，产品不得宣称能保证获奖。
