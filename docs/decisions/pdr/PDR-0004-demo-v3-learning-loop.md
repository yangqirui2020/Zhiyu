# PDR-0004 — Demo V3 产品主线收束与术语统一

## Problem

Demo V2（TASK-013/014）主流程止于「找到同桌」，匹配完成后没有发生学习：无观点碰撞、无认知变化、无知识沉淀、无下一步行动。用户指令（2026-09-01 Demo V3 收束稿）要求把半闭环升级为完整学习/知识生产闭环，并按 AGENTS.md §2 优先级 1（用户当前明确指令）覆盖旧 Golden Path 主线。

## Decision

1. **V3 Golden Path 冻结为**：看懂全班 → 课代表圆桌 → 黑板三项（全班共识/核心争议/尚未解决的问题）→ 用户表达（「听完他们，你现在怎么看？」）→ 你的一席（Candidate Seat）→ 同桌追问 → 用户回应 → 课堂笔记 → 《我的一席》→ 留下我的这一席（入席）→ 双出口（去知乎写下这一席 / 去下一间教室）。
2. **术语统一**（四词分义，不再混用）：
   - Candidate Seat = 系统发现「这里可能有你的位置」（当前观点在认知空间中的位置）。
   - 你的一席 = 用户的观点在课堂中逐渐形成的过程态。
   - 留下我的这一席 = 用户确认自己的知识产物（CTA）。
   - 入席 = 用户像素角色真正进入课堂（状态）。
3. **角色职责收束**：同桌唯一职责是「帮用户发现自己还没想完整的地方」（一次有效认知摩擦，非聊天机器人）；课堂笔记记录「我的认知变化」（个人认知，非全班 AI Summary）；黑板承载「全班共识/争议/未解决」（集体认知）。两者严格分离。
4. **多教室连接**：Classroom = 一个真实问题/一场认知讨论；教室之间通过「尚未解决的问题」因果连接（101 → 102）。
5. **不变红线**：PROD-001 的可信度披露、禁用词、Candidate 三条件 guard、Snapshot/Mock 诚实边界全部继承；圆桌/追问/笔记/我的一席在 V3 均为预生成 Mock 并明确披露，不伪装实时 AI。

## Impact

- UX-001 的 Golden Path 时序在「带入笔记」之前插入「课代表圆桌 → 黑板三项」；输入动机从「分析我的笔记」改为「听完后的表达」。
- 闭环出口从单一「去知乎 CTA」扩展为双出口；三行提纲保留为知乎草稿形态。
- 既有冻结项（产品隐喻、教室主舞台、可信度措辞、Domain/API Contract、Design Tokens）不变。

## Won't Do V3

AI 老师、无限自由聊天、真多 Agent 长轮辩论、多用户实时、好友/排行/等级/成就/道具、多同桌、真实知乎发布、复杂数据库、自由拖拽换座、复杂游戏系统。
