# V1 P0=6+1，阿问与课代表收敛

## User Problem

Golden Path 必须在 48h 达到高完成度，不能被人格、聊天和任意题能力稀释。

## Decision

P0 冻结为 6+1。阿问采用方案 A：V1 不做功能，只允许低优先级“赛后见”。课代表是静态簇 Inspector + 两个带证据、明确标注的预计算示例推演；无自由输入框。首页唯一主 CTA 进入备案教室。

## Guardrail

H13 未完成静态课代表就永久放弃聊天；H24 后所有 Feature 进入 Deferred。
