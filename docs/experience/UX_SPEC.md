# Golden Path 与 Experience Architecture

## 信息架构

- `/`：一句定义、一个备案问题、唯一主 CTA“走进这间教室”、数据来源/时间。
- `/classroom/[questionId]`：完整 Golden Path。所有详情用右侧 Sheet/Inspector；不跳转独立结果页。
- 同一时刻最多一个主要 Sheet、一个主 CTA。关闭 Sheet 后保留教室视图与选择上下文。

## 首次时序

| 时间 | 页面发生什么 | 用户应理解什么 |
|---|---|---|
| 0–400ms | 舞台、题目、样本数与模式先出现 | 这是一个真实问题形成的空间 |
| 400–1200ms | 学生从入口分批进入；总时长不随人数线性增加 | 一个学生是一条真实来源 |
| 1200–2200ms | 学生向簇中心聚拢 | 座位表示论证相似性 |
| 2200–2600ms | 簇标签、人数、独立观点出现 | 这里有多种解释，不是排行榜 |
| 2600ms+ | 一次性提示“点一个学生，看看他为什么坐在这里” | 下一步动作明确 |

Reduced Motion 直接进入稳定布局，以淡入替代飞行/聚拢。

## 精确 Golden Path

1. 首页进入备案教室；题目、Snapshot/Live 标识和抓取时间可见。
2. 入场完成后点学生；Inspector 展示结论、理由、搜索摘要片段与原链。
3. 点簇；Inspector 展示共同理由、代表来源、为什么坐一起、AI 署名，以及两个明确标为“示例推演”的按钮。
4. 在教室内点“把我的笔记带进来”；Note Sheet 打开。
5. 提交前披露第三方处理与不持久化规则；校验失败保留文本。
6. 后端只有一个响应时，UI 只显示“正在分析你的笔记”；不得伪造百分比或阶段。
7. 成功后目标 Claim 先高亮，再进入教室；空桌一次亮起；出现“这里可能有你的一席”；证据 Sheet 自动打开。
8. 依次核验：与问题相关、来自你的笔记、当前覆盖较少。每条 Evidence 可回溯。
9. 固定披露真实 N/X、模式与抓取时间。
10. 点“整理成回答提纲”只揭示三行：观点/论据/结构；主 CTA 变为“去知乎写下这一席”。

## Candidate Reveal 时序

- 0–250ms：目标 Claim 高亮，其他 Claim 降低对比。
- 250–750ms：Claim 卡沿清晰路径进入教室。
- 650–1250ms：空桌由轮廓变为琥珀实线，只播放一次。
- 1250–1550ms：文案“这里可能有你的一席”。
- 1550–1900ms：证据 Sheet 打开。

动画不得提前于真实结果返回，也不得用于遮掩等待。

## 状态级体验

| 状态 | 必须显示 | 主动作 |
|---|---|---|
| Initial | 教室定义、样本分母、来源模式 | 进入/探索 |
| Loading | 真实等待说明；不虚构进度 | Cancel（适用时） |
| Ready | 空间为视觉主体；一次性引导 | 探索/带入笔记 |
| Empty | 为什么材料不足 | 切换备案题 |
| Error | 可理解错误、输入/上下文不丢失 | Retry / Use Snapshot / Use Sample |
| Partial | 已完成项、缺失证据、为何不能完整下结论 | 查看 / Retry |
| No Candidate | 无座位及原因（跑题/已充分覆盖/证据不足） | 修改笔记 |
| Candidate | 座位 + 三项证据 + 分母 | 整理提纲 |

## 恢复与第二次操作

- 新提交取消上一请求；只接受最新 requestId。
- 修改已分析笔记立即使旧结果失效，但保留文本。
- Retry 使用不可变 `lastSubmittedText`。
- Reset 清空笔记、Claim、Seat；不重播 Classroom 入场。
- 切题可保留笔记草稿，但必须清空分析结果并重新提交。
- Classroom 切题清空选择态；返回同题不重放 Wow。
- 关闭证据 Sheet 后可从空桌再次打开。

## 可访问性与响应式

- ClassroomStage 桌面占可视宽度约 65–75%；Sheet 400–440px。
- 1440×900、1366×768 必须完整；390×844 改为纵向段落/Bottom Sheet，不机械缩成三列。
- Canvas 外提供可筛选的 DOM 观点列表；键盘可选择学生/簇。
- hover、selected、focus 不得只靠颜色；focus 可见。
- Sheet 支持 focus trap、Escape、焦点恢复。

## 固定文案

- 课代表：“AI 基于 N 篇内容归纳 · 非任何真实答主 · 不代表知乎立场”。
- Snapshot：“数据快照 · 抓取于 YYYY-MM-DD HH:mm”。
- Live：“实时数据”。未校准任意题：“未校准快速预览”。
- Candidate：“这里可能有你的一席”。
- 覆盖说明：“基于当前检索到的 N 篇内容、X 个观点簇的对比”。
- 无候选（覆盖）：“这个视角在当前样本中已有较充分讨论。”
- 无候选（跑题）：“这段笔记与当前问题的关系还不够明确。”
