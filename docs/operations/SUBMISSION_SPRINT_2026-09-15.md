## 4. 交付档位和停止扩张的时间点

**最低产品闭环：真实 Snapshot + 明示 Sample。** 用户能打开一道真实问题，查看真实来源、AI 观点分组与课堂叙事，使用明确标记的示例完成候选证据、一次追问、学习笔记和知乎出口。它是可复现的产品体验，但不是任意输入均可用。能否满足比赛资格仍以本届规则为准。

**目标闭环：真实 Snapshot + Live 个性化分析。** 用户自己的观点进入 Candidate 分析，适当时产生一席；匹配与追问参考本次观点和真实材料，回应后产物来自当前会话。模型异常保留输入，只有精确 Sample/hash 命中才允许示例回退。课堂来源模式和本次模型分析模式分别披露，不能用一个 Live 标签覆盖所有内容。

- **01:30 权限门**：官方搜索仍不可用时，先检查主办方是否提供授权数据包/导出和存储许可。浏览器登录不等于 API 权限。没有合法真实资料就仍是 Mock，不能改名 Snapshot。
- **03:00 数据门**：只核算同题去重来源，不借别题内容凑数。低于待校准的最低样本门槛，显示材料不足；改用验证通过的备案题需同步 Task/Decision。无法形成合法课堂时明确记录阻断。
- **05:00 分析门**：Live Candidate 仍不稳定时，保住真实 Snapshot + 显式 Sample 的最低闭环；不得悄悄恢复通用固定结果。
- **06:30 学习门**：动态学习产物仍不稳定时，只保留明确的示例完整学习路径；对任意输入诚实展示可完成的分析与恢复选项，不宣传完全个性化闭环。
- **08:00 功能冻结**：不再加框架、记忆、更多教室或复杂动效。只修数据真实性、主流程、部署和提交阻断项。
